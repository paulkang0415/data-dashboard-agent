# 사용 방법

## 흐름

1. 세션을 열면 에이전트가 샘플 데이터셋 3종을 자동으로 시드합니다
   (월별 매출 / 사용자 이탈 퍼널 / 웹 트래픽).
2. 왼쪽 사이드바에서 데이터셋을 선택하면 KPI 카드가 갱신됩니다.
3. 프롬프트 입력 또는 예시 칩으로 차트를 생성합니다.
4. CSV/JSON 파일을 업로드하면 새 데이터셋으로 추가됩니다.

## 프롬프트 해석

자연어 요청은 LLM Gateway(`llm.generate`, 구조화 출력)로 차트 의도
(`chartType`, `dimension`, `measure`)로 변환된 뒤, 데이터에서 실제 수치를
집계해 차트를 만듭니다. Gateway 오류나 부적절한 응답 시 규칙 기반 해석으로
자동 폴백합니다.

| 의도 | 키워드(폴백 기준) | 결과 |
|---|---|---|
| 추이 | 추이·월별·trend·시계열 | 라인 차트(시계열) |
| 퍼널 | 이탈·퍼널·구간·전환 | 가로 막대 + 잔존율 KPI |
| KPI 요약 | KPI·핵심·요약·대시보드 | KPI 카드 + 분포 막대 |
| 기본 | (그 외) | 첫 범주형 × 첫 수치형 막대 |

예: `월별 판매량 추이 차트 만들어줘`, `사용자 이탈 구간 분석해줘`,
`핵심 KPI 요약 대시보드 구성해줘`.

## 업로드 형식

- **CSV**: 첫 줄은 헤더. 숫자처럼 보이는 셀은 자동으로 수치형 처리.
- **JSON**: 행 객체 배열 `[{...}, ...]` 또는 `{ "columns": [...], "rows": [...] }`.

업로드 파일은 세션 파일로만 처리되며 외부로 전송되지 않습니다(아래 privacy.md).
